# Contribuir
Use Node.js 22.13+, `npm ci` e `npm test`. Compile os componentes nativos conforme README. Adicione testes para alterações de foco, atalhos, persistência e recuperação. Teste os atalhos com teclado físico: eventos simulados não provam comportamento real do macOS.

Não inclua dados pessoais, áudios de usuários, bancos, credenciais ou exportações. Use fixtures sintéticas em diretório temporário. Mantenha o processamento local e a checagem de destino antes de colar. Alterações visuais usam os tokens semânticos existentes.
