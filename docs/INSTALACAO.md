# Instalação para alunos

Este guia corresponde à [prévia pública 0.2.0](https://github.com/torriani/lume-flow/releases/tag/v0.2.0-preview.1). Veja o [manual completo](produto/MANUAL.md) e as [diferenças das alterações locais](produto/VERSOES.md).

1. Em “Sobre Este Mac”, veja se o processador é Apple M1/M2/M3/M4 ou posterior (arm64) ou Intel (x64). É necessário macOS 14 ou superior.
2. Extraia o ZIP correspondente e mova LumeFlow.app para Aplicativos. Não use o aplicativo dentro do ZIP.
3. Abra o LumeFlow e aguarde “Motor pronto”. Os modelos já acompanham o pacote.
4. Em Preferências, permita Microfone. Em Ajustes do Sistema → Privacidade e Segurança → Acessibilidade, autorize LumeFlow. Autorize Monitoração de Entrada se solicitada.
5. Em Preferências do LumeFlow, clique em Ativar Fn. Em Teclado, configure a tecla Fn/Globo para não fazer nada. Pause outro aplicativo que use o mesmo atalho.
6. Clique num editor vazio, segure Fn e diga uma frase. Solte e confirme texto, áudio no histórico e botão Copiar.
7. Teste Fn + Espaço, solte ambas e confirme que continua gravando. Clique num campo e pressione Fn para encerrar. Teste também o botão quadrado de parar.

Esta prévia não está notarizada. O macOS pode bloquear a abertura ou pedir autorização novamente após atualizações. Não desative as proteções globais do sistema. Para distribuição sem esse atrito, é necessária uma release assinada com Developer ID e notarizada.

Nenhum aluno recebe dados do autor. Cada conta macOS cria seu histórico local vazio. Não compartilhe a pasta de dados nem um backup pessoal. O aplicativo permanece local e não envia seu áudio a APIs externas.

Se não inserir o texto, use Copiar no histórico. Se falhar a transcrição, use Recuperar quando houver áudio. Para suporte, envie versão, arquitetura, versão macOS e descrição do erro; não envie gravações pessoais sem necessidade.
